# godot-oi

Oi bindings for Godot.

- `godot/` is the module a game imports with `use godot`
- `templates/` has files meant to be symlinked/copied into your project
- `examples/` are Godot projects

```sh
just run bare
```

Requires `oi` and `godot` (4.5+).
